# Northline Academy web app

Vite, React, Tailwind, and TanStack Query, Router, and Table. The API lives in `../backend`.

Install and run the full stack from the repository root:

```bash
npm install
npm run dev
```

That starts this app on port 4317 (with `/api` proxied to FastAPI on port 8741). See the repository [README](../README.md) for demo accounts.
